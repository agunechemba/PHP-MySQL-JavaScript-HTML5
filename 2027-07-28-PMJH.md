# About PHP, MySQL, JavaScript & HTML5 — All-in-One

This project is an **interactive storybook** that teaches web development from first principles. It adapts Steve Suehring and Janet Valade's *PHP, MySQL, JavaScript & HTML5 All-in-One For Dummies* into a page-turning reading experience built with plain HTML, CSS, and vanilla JavaScript. It runs entirely in the browser — no build tools, no dependencies, no server required.

The book is a refactored and illustrated adaptation of the original, rewritten with the same clear, hands-on spirit but arranged as a sequence of storybook pages that you turn one at a time. All mistakes in the retelling are the adapter's own.

## The Journey in Seven Parts

The book is divided into seven progressive minibooks, each focused on a distinct layer of the web:

| Book | Title | Focus |
|------|-------|-------|
| One | **Getting Started with PHP & MySQL** | The languages of the web, installing Apache, PHP, MySQL, and XAMPP. |
| Two | **HTML and CSS** | Page structure, styling, and web forms. |
| Three | **JavaScript** | Variables, loops, functions, the DOM, jQuery, events, and debugging. |
| Four | **PHP** | Scripting, files, object-oriented programming, security, and sessions. |
| Five | **MySQL** | Database design, SQL queries, and connecting PHP to MySQL. |
| Six | **Web Applications** | Helper functions, web services, form validation, and a members-only site. |
| Seven | **PHP and Templates** | Configuring PHP and building a templating system. |

Each chapter includes:

- A short **story** that introduces the concept in plain language.
- A **Key Ideas** box summarising the takeaway.
- **Try It Yourself** questions and exercises.
- Illustrated **code examples** with syntax highlighting.

## How to Use the Book

The book is presented as a sequence of pages, like a physical storybook.

- **Turn pages** with the on-screen buttons, or with the **left and right arrow keys**.
- **Jump to any chapter** using the clickable Table of Contents.
- A **reading progress bar** at the top shows how far you've read.
- A **page indicator** in the corner tells you your current page.
- The layout is **responsive** and works on phones, tablets, and desktops.
- If JavaScript is disabled, all pages stack into a single scrollable document so the content remains accessible.
- Reduced-motion preferences are respected.

## Files

The project consists of three files:

- `index.html` — the book content and structure.
- `styles.css` — the storybook styling and responsive layout.
- `script.js` — the page-navigation engine.

To run it, simply open `index.html` in any modern browser.

## A Note for the Reader

This book is meant to be read with your fingers on the keyboard. Type every example into a text editor. Save it. Reload the browser. Break it. Fix it. Make it your own. The loop — *edit, save, reload, repeat* — is the whole secret of web development, and no book can do it for you. Every programmer, every day, writes mistakes. That is how we learn.
